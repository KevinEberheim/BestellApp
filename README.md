# BestellApp

BestellApp is a web-based food ordering application that allows users to browse and order from a selection of burgers, pizzas, and salads. It features a responsive design with a basket system for managing orders and a confirmation dialog upon checkout.

## Features

- Browse menu categories: Burgers, Pizzas, and Salads
- Add items to a shopping basket
- View subtotal, delivery fee, and total cost
- Responsive design for mobile and desktop
- Order confirmation dialog
- Toggle basket visibility on mobile

## Installation

No installation required! Simply:

1. Clone or download the repository
2. Open index.html in any modern web browser
3. Start exploring BestellApp!

## Usage

- Open the app in your browser.
- Select a category to view available dishes.
- Click on dishes to add them to your basket.
- Review your basket and proceed to checkout by clicking "Buy Now".
- Confirm your order in the dialog.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Project Structure

- `index.html`: Main HTML file
- `styles/`: Directory containing CSS files (standard.css, fonts.css, basket.css, assets.css, responsive.css)
- `scripts/`: Directory containing JavaScript files (templates.js, script.js, dialog.js)
- `assets/`: Directory for images and icons

## Browser Compatibility

This application is compatible with modern web browsers including:

- Google Chrome (latest version)
- Mozilla Firefox (latest version)
- Microsoft Edge (latest version)
- Safari (latest version)

For the best experience, use a browser that supports ES6+ JavaScript features.
